# Рукасов Владислав Ік-42
## Опис проєкту
Цей репозиторій містить рішення алгоритмічних задач для Варіанту 1 "Number Pattern Analyzer". Код написано мовою JavaScript (ES6+) з використанням сучасного синтаксису, умовних конструкцій та обробкою крайніх випадків (edge cases).

## Реалізовані алгоритми та їх складність:
1. **FizzBuzz Classic**
   - **Складність:** Час O(n), Пам'ять O(n).
   - **Опис:** Проходимо циклом від 1 до n, перевіряючи кратність на 15, 3 та 5 за допомогою оператора `%`.
2. **Number Sign**
   - **Складність:** Час O(1), Пам'ять O(1).
   - **Опис:** Використано структуру `if` для точкової обробки особливих станів (`NaN`, `0`, `-0`, `Infinity`).
3. **Leap Year Checker**
   - **Складність:** Час O(1), Пам'ять O(1).
   - **Опис:** Використано оптимізований логічний вираз із урахуванням правил подільності на 4, 100 та 400.
4. **Triangle Type Classifier**
   - **Складність:** Час O(1), Пам'ять O(1).
   - **Опис:** Реалізовано валідацію нерівності трикутника та класифікацію за допомогою строгого порівняння `===`.
5. **Grade Letter Calculator**
   - **Складність:** Час O(1), Пам'ять O(1).
   - **Опис:** Використано оператор остачі від ділення `% 10` для визначення модифікаторів `+` (бали 7-9) та `-` (бали 0-2).
